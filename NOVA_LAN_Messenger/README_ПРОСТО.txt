NOVA MESSENGER — ЗАПУСК В ОДИН КЛИК
=====================================

САМОЕ ГЛАВНОЕ
1. Распакуй архив в любую папку.
2. Дважды нажми файл NOVA.bat.
3. Всё. Программа сама:
   - найдёт уже работающий NOVA в домашней/локальной сети; или
   - запустит сервер на этом компьютере, если сервер ещё не запущен;
   - откроет окно мессенджера в браузере.
4. Создай аккаунт или войди. После успешного входа появится твой GIF,
   нажми «ПРОДОЛЖИТЬ» и пользуйся чатом.

НИКАКИЕ IP-АДРЕСА И ПОРТЫ ВВОДИТЬ НЕ НУЖНО.
На каждом компьютере просто запускается NOVA.bat. Компьютеры должны
быть подключены к одной домашней сети Wi-Fi или одному роутеру.

ВАЖНО ПРИ ПЕРВОМ ЗАПУСКЕ
Windows может один раз спросить, разрешить ли Python доступ к сети.
Нажми «Разрешить доступ» только для частных сетей. Это системная защита
Windows, её нельзя безопасно отключить из программы.

ЕСЛИ PYTHON НЕ УСТАНОВЛЕН
Нужен Python 3.9 или новее. Установи его один раз с python.org и поставь
галочку «Add Python to PATH». Никакие библиотеки отдельно устанавливать
не надо. После этого всегда запускай только NOVA.bat.

АККАУНТЫ И ПЕРЕПИСКИ
- Аккаунты и история сообщений сохраняются в папке data на компьютере,
  который первым запустил сервер.
- Данные сохраняются после выключения программы и перезагрузки Windows.
- Переданные файлы сохраняются в папке media.
- Пароли хранятся в виде PBKDF2-хешей с солью, а не обычным текстом.
- Резервная копия: периодически копируй папки data и media.

КАК ВЫКЛЮЧИТЬ
На компьютере, который первым запустил NOVA и стал сервером, закрой чёрное
окно запуска. Это остановит сервер. Пока сервер выключен, другие устройства
не смогут обмениваться сообщениями. При следующем запуске NOVA.bat сервер
поднимется снова с сохранёнными аккаунтами и сообщениями.

ЕСЛИ ДРУГ НЕ ВИДИТ ТЕБЯ
- Убедитесь, что оба компьютера в одной Wi-Fi/локальной сети.
- На компьютере сервера разрешите Python в брандмауэре Windows для частной сети.
- Не используйте гостевую Wi-Fi сеть с изоляцией клиентов.

ОГРАНИЧЕНИЯ И БЕЗОПАСНОСТЬ
- Это приложение для домашней/учебной локальной сети, не для интернета.
- HTTP-соединение в локальной сети не шифруется. Не используйте важные пароли.
- Вложения до 15 МБ.
- Для показа указанного GIF после входа нужен доступ к Tenor/интернету.
  Сам локальный чат и хранение сообщений работают внутри локальной сети.
- Не настраивайте проброс портов роутера в интернет.
